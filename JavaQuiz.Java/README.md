
### PRACTICA INTEGRADORA UNIDAD3#

En este proyecto estaremos desarrollando una aplicación por consola de un concurso de preguntas llamado JavaQuiz,

se tratan de seis preguntas divididas en dos rondas  sobre conceptos básicos de java 

Cada pregunta mostrará un enunciado y tres opciones (A, B y C). El usuario introducirá una letra; el programa indicará si ha acertado y, al terminar las seis preguntas, mostrará el número total de aciertos.
